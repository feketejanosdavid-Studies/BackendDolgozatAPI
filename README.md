# Backend dolgozat API telepítése / indítása

```bash
git clone https://github.com/feketejanosdavid-Studies/BackendDolgozatAPI.git
```

## Adatbázis feltelepítése

erre használd a database/backenddolgozat.csv fájlt

ehez írd be:
```bash
npm i 
```

XAMPP-on egy mysql-t kell elindítani
Majd utánna:
```bash
node app.js
```
